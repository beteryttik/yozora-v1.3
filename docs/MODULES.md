# Модули

## Оптимизация
- ParticleCull — частицы дальше радиуса не создаются (по умолчанию 48 блоков)
- EntityCull — сущности дальше 64 блоков не рендерятся
- BlockEntityCull — блок-сущности (сундуки, печи) дальше 64 блоков не рендерятся
- NoClouds — слой облаков отключается на уровне настроек игры
- FpsLimiter — ограничение FPS для стабильного фреймтайма и охлаждения железа

## Визуал
- Zoom — зум на C (множитель настраивается)
- FullBright — гамма до 16
- NoHurtCam — убирает тряску камеры при уроне
- CustomCrosshair — свой прицел

## HUD
Fps, Coordinates, Ping, Keystrokes, Direction, Speed, Server, Clock, Armor

## Движение
- SafeWalk — не срываешься с обрыва при ходьбе
